# Application Shell Specification

## Overview
A calm top bar shell for a tenant portal: logo on the left, two navigation items in the middle, the signed-in user on the right. On phones the navigation moves into a bottom bar.

## Navigation Structure
- Readings → Meter Readings
- Account → Account

## Layout Pattern
Top navigation with a centered content column (max 640px) on a light background. Bottom tab bar below 640px.

## User Menu
Top right: avatar with the tenant name, menu with Profile and Sign out.

## Responsive Behavior
- **Desktop:** Top bar with inline navigation
- **Tablet:** Same as desktop
- **Mobile:** Top bar with logo and avatar, bottom bar with the two navigation items
